The resulting library, ProtoQuill, became the official Scala 3 implementation of Quill.

  • Originated the project: identified the Scala 2 → Scala 3 port as an effort I could own end to end, and pitched it in parallel to the library's lead maintainer and my faculty advisor to establish it as a sponsored senior capstone.
  • Recruited and led a team of 5–6 developers sourced through my Drexel network and their extended connections—setting technical direction, dividing ownership of the AST surface, and running delivery through Jira and GitHub.
  • Built the lifters and unlifters that translate Scala 3 syntax tree elements into Quill's internal query AST, covering core query constructs including select, filter, and order.
  • Designed the compiler-level pipeline end to end: read Scala syntax tree elements at compile time, convert them into a custom query AST, then render that AST into whichever target query language the caller selected—preserving Quill's compile-time query generation on an entirely new metaprogramming foundation.
  • Developed against Scala 3 Milestone and Release Candidate builds before the language was stable, working without a settled API surface and surfacing compiler-level regressions in the process.
  • Built the team's quality infrastructure from scratch—no testing library existed for Scala 3 at the time, so established review standards and verification processes in place of tooling that did not yet exist.
  • NASDAQ ran Quill in production, making the port directly relevant to the firm; portions of the work were approved on company time, with the balance carried after hours alongside the lead maintainer.
  • Contributed to a library that reached production release: ProtoQuill is published to Maven Central as the quill-*_3 artifacts and is now maintained under the ZIO organization as Quill's Scala 3 line.
